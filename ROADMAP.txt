Architecture summary
--------------------
- CMakeLists.txt is the aggregation layer. It compiles selected source files from
  QuantumCore, ClassicalMechanicsCore, ElectrodynamicsCore, FluidDynamicsCore,
  NuclearCore, OpticsCore, SolidStateCore, and ThermodynamicsCore as object libraries.
- PhysicsEngine is a static library containing those objects plus this repository's
  metadata, async, and coupling implementations.
- PhysicsEngine.h is the master public include and exposes the module C APIs plus
  the engine-level APIs.
- PhysicsEngine.cpp owns the version string and eight-entry module registry.
- PhysicsAsync implements a process-global worker pool using std::thread, mutexes,
  condition variables, a task queue, completion tracking, and atomic counters.
- PhysicsCoupling implements formula-based bridge functions between physics domains.
- include/physics contains a separate collision subsystem based on simple shape types,
  std::variant shape storage, broadphase AABB filtering, and narrowphase function dispatch.
- main.cpp is a smoke/example executable, not yet a comprehensive integration test.
- tests/ contains focused executable tests for the collision subsystem.
